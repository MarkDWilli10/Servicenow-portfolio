# Project 08 – User Administration

## Objective

Demonstrate the ability to manage users, groups, roles, and access within ServiceNow while following security and least-privilege best practices.

---

- User Management
- Group Administration
- Role Assignment

- Identity Management

---

## What is User Administration?

User Administration is the process of managing who can access ServiceNow, what they can see, and what actions they are allowed to perform.

Proper user administration ensures users have the correct level of access while protecting sensitive company information.

---

## Example Scenario

A new Service Desk technician joins the company.

The administrator must:

1. Create a new user account.
2. Assign the user to the Service Desk group.
3. Grant the appropriate Service Desk role.
4. Verify login access.
5. Confirm the technician can create and update incidents.
6. Ensure the user cannot access administrator-only features.

---

## Common User Administration Tasks

- Create users
- Disable users
- Reset passwords
- Unlock accounts
- Create groups
- Add users to groups
- Assign roles
- Remove unnecessary access
- Review permissions
- Audit user accounts

---

## Security Best Practices

- Follow the Principle of Least Privilege.
- Grant only the access required for the user's job.
- Regularly review user permissions.
- Remove inactive accounts promptly.
- Audit administrative access.

---

## Business Value

Effective user administration:

- Protects sensitive data
- Reduces security risks
- Simplifies onboarding and offboarding
- Improves compliance
- Ensures employees have the tools they need
