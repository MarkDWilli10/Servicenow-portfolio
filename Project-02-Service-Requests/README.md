## What is a Service Request?

A Service Request is a request from a user for something they need—not something that is broken.

Examples include:

- Password reset
- New laptop
- Software installation
- VPN access
- Shared folder access
- Email distribution group
- New employee onboarding
- Hardware replacement

---

## Scenario

A new employee needs Microsoft Office installed on their company laptop.

---

## Process

1. User submits a request through the Service Catalog.
2. Service Desk reviews the request.
3. Verify the user's identity.
4. Confirm manager approval if required.
5. Assign the request to the Desktop Support team.
6. Install Microsoft Office.
7. Test the installation with the user.
8. Document all work performed.
9. Mark the request as fulfilled.
10. Close the request.

---

## Assignment Group

Desktop Support

---

## Priority

Normal

---

## Expected Outcome

The user receives Microsoft Office and confirms it is working correctly.

---

## Lessons Learned

Unlike an Incident, a Service Request is used to provide a standard service rather than restore a service that has failed.

Understanding the difference between Incidents and Service Requests is fundamental for ServiceNow administrators and IT support professionals.
